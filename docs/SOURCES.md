# Sources, rights, and coverage

These policies were checked against official documentation on 2026-10-10. Successful HTTP access alone is not permission to collect or republish content.

| --- | --- | --- |

Its usage API contains site-wide totals, not per-paper counts. Preprint identity follows the official category/server, including newer DOI prefixes such as 10.64898. |
| [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | Exact journal ISSNs and publisher-deposited `published-online` dates; bibliographic metadata | Metadata is reusable; abstracts are not blanket licensed and are excluded. [Keyless budget](https://help.openalex.org/access/example-costs/) is limited; no API key or paid plan is used. |
| [biorxiv-top public numerical snapshot](https://github.com/RobertoDF/biorxiv-top/blob/data/usage.json) | DOI-keyed available monthly full-text/PDF numerical facts, pinned to the data branch commit | User-authorized factual numerical reuse. ## Selection

Journal identities are the exact configured ISSNs in [sources.json](../config/sources.json). Nature Neuroscience and Journal of Neuroscience use their neuroscience journal scope. For eLife, all three PLOS journals, Nature, Nature Methods, and Nature Communications, at least one of the top three OpenAlex topics must have field ID `https://openalex.org/fields/28` and score at least 0.35. The evidence and score are retained. PLOS candidates additionally require the publisher Neuroscience category and exact eISSN/pISSN; partial document fragments are excluded and repeated DOI rows never multiply counts. Unknown/non-neuroscience classifications are excluded from multidisciplinary lists; relevant papers may be missed. Included records without topics remain explicitly unknown.

Initial/weekly ingestion requests the rolling past calendar year of v1/first-online dates. Regular metadata refreshes overlap the previous eight days to recover indexing delays; weekly repair revisits the whole year, topic classification, versions, and related publication links. Missing initial v1 records are resolved from the official single-DOI endpoint in a bounded queue; unresolved v1 records are omitted and counted. Corrections and other `journal-article` records can be included by the depositing source. No promise of complete publisher inventories is made.

## Raw metric semantics

`accesses` and `citations` are independent nullable integers. Zero is measured zero; null is missing. Each measured value requires a source and UTC observation timestamp. Raw accesses require a documented definition, aggregation/window, and collection/republication permission. Cross-publisher raw values may cover different periods and events and are not fully comparable.

Preprint readership sums the available monthly full-text views and PDF downloads in the independent numerical snapshot. The source cohort initially starts in May 2026 and covers only part of our official rolling-year corpus. Missing months are not invented as zeros. Upstream collection parses a bounded HTML region, so complete lifetime/all-version coverage is unverified; the current month is partial. Keep source commit/root update time, each paper's upstream collection date, our retrieval timestamp, and channel breakdown. Filter publication dates by our verified v1 date; do not use the snapshot's paper date or pretend to filter readership by day. Previously measured rows survive missing values or source failure.

The original five published journals have no approved publisher-access feed configured. Access sorting prominently falls back to measured citations, then newest if every measurement in the current filtered view is missing. Unmeasured values have no rank; measured ties share ranks. No normalized score or weighted composite is computed. Known published preprints are hidden by default, with an include toggle. Unlinked publication status remains uncertain.

OpenAlex counts describe one work and can merge preprint/publication versions. A preprint and its related published record can appear in their respective tabs, with the same OpenAlex work ID visible. Their citations are never added together. Resolved aliases use the canonical DOI in subsequent bulk refreshes, so counts and topics continue updating. Unresolved singleton matches retry after seven days through a bounded queue, allowing later indexing. A missing DOI match or failed request does not erase a previous measurement. The measurement timestamp remains the last successful observation, not the refresh attempt time.

PLOS's primary raw metric is `counter_total_all` (source-defined all-time total views); `counter_total_month` is separately labelled last 30 days. We request the entire rolling-year neuroscience cohort in one shared metadata/metric pass every six hours, avoiding per-paper calls and redundant schedules. Source-reported zero may be an index default awaiting update, not proof of no readers. The API `timestamp` is an index timestamp, distinct from our successful metric retrieval timestamp and not a guaranteed metric cutoff.

eLife uses each channel's `totalValue`, not the returned page's periods or any inferred missing-day zeros. Page views are primary; downloads are a separate metric and never added to page views. Both aggregate all eLife versions and can include readership before VOR publication. Version DOI suffixes map to the same numeric article ID. Official histories must establish a published VOR; reviewed-preprint-only and unverified entries are excluded from Published and counted. The first VOR `published` date replaces the Crossref candidate date only after verification; earlier reviewed-preprint and external-preprint dates remain explicitly separate. No creation, deposit, revision, index, or fetch timestamp becomes the publication date.

## Optional readership imports

`ingest/readership.py` provides permission-aware import validation and a serial rate-limited queue extension point. Restricted publisher adapters remain disabled in configuration. An enabled provider must explicitly record collection/republication permission, an HTTPS permission evidence URL, and a metric definition. After configuring a verified permitted provider, `python -m ingest.readership --file approved-counts.json` validates all imports before persisting `data/readership.json`; the next refresh attaches matching DOI measurements. The latest cumulative snapshot replaces earlier snapshots; counts are never summed. Windowed metrics need a stated window. No provider is automatically activated, and no sample import is published as production data. OpenAIRE repository views/downloads must remain separate fields rather than being silently mapped to publisher accesses.

## Reliability and source rights

In source diagnostics, `requested_dois` is the number of DOI candidates in the last lookup pass (including records later excluded from the visible corpus). `rows` counts API rows returned across requests and may include repeated canonical works and singleton alias results. `unmatched` is the final number of retained DOI candidates without a resolved OpenAlex work after enrichment, recalculated from the cache. `aliases_deferred` records unresolved alias lookups left in the bounded queue for that lookup pass; it is not a count of missing citations in the displayed corpus. Public corpus citation/topic coverage is computed separately from included records. A diagnostic counter bug that initially counted resolved works as unmatched was corrected with a regression check.

Source requests are serial, bounded, and use an honest project user agent. Retry-After is respected: long waits are deferred rather than retried early. Restricted hosts are refused by the metadata client. Source failures retain last-good state and report partial coverage; validation failure leaves the prior public snapshot intact. The initial empty scaffold is never deployed.

Only bioRxiv abstracts marked CC-BY, CC-BY-SA, or CC0 are redistributed, with paper authors, source links, and license attribution. Other abstracts link to the source. The original code license, GPL-3.0-only, does not extend to third-party metadata or literature. No full text or unlicensed publisher abstract is included. The browser uses no third-party analytics, fonts, or runtime API credentials.
